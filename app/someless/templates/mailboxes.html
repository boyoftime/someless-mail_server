Set it up on a device

Add to a phone or computer.

{% for key, label in [("android", "Android"), ("iphone", "iPhone"), ("windows", "Windows PC")] %} {% endfor %}

In the Gmail app:

  1. Tap your profile picture at the top right, then Add another account, and choose Other.
  2. Type , and tap Manual setup. Choose Personal (IMAP), and type the mailbox's password.
  3. Incoming server: {{ server }}, with the whole address as the username. If it asks, port {{ ports.imap }} and SSL/TLS.
  4. Outgoing server: {{ server }}, with Require sign-in on. If it asks, port {{ ports.smtp_ssl }} and SSL/TLS.
  5. Choose how often to check for mail, type your name as people see it on your mail, and tap Next. The mail shows up in Gmail.
Download profile
  1. Point the iPhone's camera at this code, and tap the link that shows up. Safari asks to download a configuration profile: tap Allow.
  2. Open Settings, and tap Profile Downloaded near the top (or General → VPN & Device Management).
  3. Tap Install, and type the iPhone's passcode. It says Not Signed: that's expected for a profile from your own server. Tap Install again.
  4. Type your name, as people see it on your mail, and the mailbox's password. The mail shows up in the Mail app.

The code works for an hour, on an iPhone that can reach this panel. On the iPhone already? Tap Download profile. It works on a Mac too: open it, then install it in System Settings, under Profiles or Device Management.

In Outlook, the mail app of Windows 11:

  1. Open Settings (the gear at the top right), then Accounts → Email accounts, and click Add account.
  2. Type , click Continue, and choose IMAP.
  3. Type the mailbox's password, and click Show more.
  4. Incoming (IMAP) server: {{ server }}, port {{ ports.imap }}, SSL/TLS. Outgoing (SMTP) server: {{ server }}, port {{ ports.smtp_ssl }}, SSL/TLS, with the same username and password.
  5. Click Continue. The mail shows up in Outlook.

Classic Outlook: File → Add Account, then Advanced options → Let me set up my account manually, and choose IMAP, with the same settings. Thunderbird or another app: use the details on the other side of this card.
