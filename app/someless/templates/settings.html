With Nginx Proxy Manager

Someless Mail is on Nginx Proxy Manager's Docker network already (nginx-proxy, in its docker-compose.yml).

1At your domain provider, add two A records

{% for host in ("panel", "webmail") %} {% endfor %}
TypeHostValue
A {{ copy_box(host, "Copy the host") }}{{ host }}.{{ secure.domain }} {% if secure.address %}{{ copy_box(secure.address, "Copy the address") }}{% else %}Your server's public IP address{% endif %}

2In Nginx Proxy Manager, add two proxy hosts

SettingWeb interfaceWebmail
Domain names{{ copy_box(panel_name, "Copy the domain name") }}{{ copy_box(webmail_name, "Copy the domain name") }}
Schemehttphttp
Forward hostname / IP{{ copy_box("someless-mail", "Copy the hostname") }}{{ copy_box("someless-mail", "Copy the hostname") }}
Forward port{{ copy_box("17080", "Copy the port") }}{{ copy_box("17090", "Copy the port") }}
Block common exploitsOnOn
SSL tabRequest a new SSL certificate, with Force SSL and HTTP/2 Support on

3Then

  • Open https://{{ panel_name }} and log in: from now on, use that address.
  • In Settings → Miscellaneous → Webmail address, type https://{{ webmail_name }}, so the Mailboxes page opens the webmail there.
  • Close the way in by IP: in docker-compose.yml, put a # at the start of the "17080:17080" and "17090:17090" lines, then run docker compose up -d.
  • The mail server name, {{ secure.mail_name }}, keeps its own proxy host, with SSL off: see Mail server name.

Without Nginx Proxy Manager

  • Install it: it's one Docker container, and gets and renews the certificates for you. Follow its guide at nginxproxymanager.com, put it on a Docker network named nginx-proxy, then do the steps above.
  • Or use Caddy, installed on the server itself: it gets the certificates by itself too. Put this in its Caddyfile, and reload it:
{% set caddyfile = panel_name ~ " {\n reverse_proxy 127.0.0.1:17080\n}\n" ~ webmail_name ~ " {\n reverse_proxy 127.0.0.1:17090\n}\nhttp://" ~ secure.mail_name ~ " {\n reverse_proxy 127.0.0.1:17081\n}" %} 
{{ caddyfile }}

The mail server name stays on plain http:// there on purpose: Someless Mail gets its certificate itself. Then, in docker-compose.yml, publish the three ports to the server itself only, so they open only through Caddy: "127.0.0.1:17080:17080", "127.0.0.1:17090:17090" and "127.0.0.1:17081:17081", and run docker compose up -d.

Neither? The panel keeps working at http://{{ secure.address or "your-server-ip" }}:17080, unencrypted. Use it only from networks you trust, and let only your own IP address reach it: sudo ufw allow from YOUR-IP to any port 17080 proto tcp.
